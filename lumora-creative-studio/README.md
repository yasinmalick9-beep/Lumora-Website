# Lumora — Creative Digital Studio

A responsive one-page website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure
- `style.css` — layout, colors, responsive design, and animations
- `script.js` — mobile navigation and demo contact form

## Run locally
Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Publish with GitHub Pages
1. Create a **Public** GitHub repository.
2. Upload these three files (keep `index.html` in the repository root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear.

The contact form is a front-end demo; it displays a confirmation message but does not send email.
